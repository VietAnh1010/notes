### Environment variables

$USER: the current user

### Executable configuration

update-alternatives --config <name>: choose which version of <name> to use

### Directory processing

find <repo> -maxdepth 1 -type f -name <pattern>: find files matching <pattern> directly in <repo> (no subdirectories)

### Text processing

cut -d <delimiter> -f <field-list>: split each line by <delimiter> and print the chosen fields
> For example: `cut -d "," -f "1, 2"` on `foo, bar, baz` will return `foo, bar`

### Groups and users

id -g -n: show the current user's primary group
groups: show all of the current user's groups
> Every user has exactly one primary group and any number of other (supplementary) groups
getent passwd: show all users on the current machine
getent group: show all groups on the current machine
usermod -aG <group> <user>: add <user> to <group>
