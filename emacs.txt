### Emacs key bindings

A-/: auto complete
C-x C-f: open a file
C-x u: undo
C-a: go to the beginning of line
C-e: go to the end of line
C-k: remove a line, start from the current cursor
C-x C-c: quit
C-x C-s: save
C-w: cut
C-y: pastes
C-s: search, then C-s for next match
C-r: search backward
C-x o: go to other window
C-x <number>: split window
C-x 4 f: open a new file in a separate buffer
C-x k: kill buffer
C-u 0 <command>: pass 0 as argument to <command>
C-h v: see variable current value
M-f: move forward by one word
M-b: move backward by one word
M-<number> <command>: repeat <command> <number> times
M-w: copy
M-x replace-string: replace
M-;: wrap the block in comment
M-x term: open terminal, using terminal bindings
M-x shell: open terminal, using emacs bindings
M-x bytecode-recompile-directory: recompile emacs lisp code (emacs package)
M-: (colon): evaluate emacs lisp expression

### Emacs lisp

(add-to-list 'load-path "."): add working directory to load path (for bytecode compilation, etc.)

### emacs executable (CLI)

emacs --batch -L <load-path> -L <load-path> ... --eval <command>: evalute emacs command, using load-path, without using GUI
> For example, to compile an `.el` file using the current directory as load path, run `emacs --batch -L . --eval '(byte-compile-file "file-name.el")'`

### Proof General (installing a fork from a local checkout)

M-x package-delete RET proof-general RET: remove the MELPA copy
git clone <fork-url> <checkout> -b <branch>: clone the fork

cd <checkout> && make clean; make: byte-compile the checkout
> Prepend EMACS=<path-to-emacs> if make picks the wrong emacs

C-u M-x package-vc-install-from-checkout RET <checkout> RET proof-general RET: link the checkout into the ELPA directory
> Write nothing to the init file
> The C-u is required. Without it the package name is inferred from the base name of <checkout>

M-x package-vc-rebuild RET proof-general RET: rebuild after updating the checkout

C-h v proof-home-directory: show which PG is loaded
> No require or load line is needed: proof-general-autoloads.el derives the PG root from load-file-name
> Merge upstream with git merge -X ignore-space-change master: coq-smie.el is indented with spaces in the fork and tabs upstream
> Check for leaked tabs with grep -cP '^\t' coq/coq-smie.el
